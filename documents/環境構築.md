## DATABASE 構築
### リレーショナル データベース (TypeScript および Prisma Postgres)
TypeScript プロジェクトを初期化し、開発依存関係として Prisma CLI を追加
```
npm init -y
npm install prisma typescript tsx @types/node --save-dev
```

```
npx prisma init
```

### データを書き込む
index.ts.  
```
import { PrismaClient } from "../src/generated/prisma";

const prisma = new PrismaClient()

async function main() {
  const alice = await prisma.user.upsert({
    where: { email: 'alice@prisma.io' },
    update: {},
    create: {
      name: 'Alice2',
      email: 'alice@prisma.io',
    },
  })
  const bob = await prisma.user.upsert({
    where: { email: 'bob@prisma.io' },
    update: {},
    create: {
      name: 'Bob2',
      email: 'bob@prisma.io',
    },
  })
  console.log({ alice, bob })
}
main()
  .then(async () => {
    await prisma.$disconnect()
  })
  .catch(async (e) => {
    console.error(e)
    await prisma.$disconnect()
    process.exit(1)
  })

```

### コードを実行
```
/workspace/nextjsapp/prisma # npx tsx index.ts
{
  alice: { id: 1, name: 'Alice2', email: 'alice@prisma.io' },
  bob: { id: 2, name: 'Bob2', email: 'bob@prisma.io' }
}
```
補足:からむ名を間違えてマイグレーションしたとき  
1. prisma/schema.prismaを編集  
2. リセットする  
```
npx prisma migrate reset
```
3. Prisma Migrateを実施  
```
npx prisma migrate dev --name add-img-to-user
```
4.データ挿入  
```
/workspace/nextjsapp # npx tsx ./prisma/seeds/index.ts
```
上記で無理な場合。データベースをシードする  
```
/workspace/nextjsapp #　npx prisma db seed
```

エラー文.
```
10.93 29:5  Error: A `require()` style import is forbidden.  @typescript-eslint/no-require-imports
10.93 172:27  Error: A `require()` style import is forbidden.  @typescript-eslint/no-require-imports
10.93 
10.93 info  - Need to disable some ESLint rules? Learn more here: https://nextjs.org/docs/app/api-reference/config/eslint#disabling-rules
10.96 error Command failed with exit code 1.
10.96 info Visit https://yarnpkg.com/en/docs/cli/run for documentation about this command.
------
failed to solve: process "/bin/sh -c yarn build" did not complete successfully: exit code: 1
```
解消法.
nextapp/next.config.tsを下記のようにする.
```
const nextConfig: NextConfig = {
  /* config options here */
  eslint: {
    // ビルド時の ESLint エラーで止まらないようにする
    ignoreDuringBuilds: true,
  },
};
```
